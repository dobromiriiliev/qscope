# Hackathon checklist

## Core science

- [ ] Finalize TFIM parameters and drift scenarios.
- [ ] Confirm the chosen experiments are physically informative.
- [ ] Get one hidden coupling reconstructed end to end.
- [ ] Get active selection running.
- [ ] Benchmark against random and fixed selection.

## Code

- [ ] Fresh clone installs.
- [ ] `qscope demo` runs locally.
- [ ] `qscope benchmark` runs locally.
- [ ] Tests pass.
- [ ] No credentials in repo.
- [ ] MIT license present.

## Qollab

- [ ] Project published and runnable.
- [ ] Project page explains problem, method, setup, and limitations.
- [ ] GitHub linked.
- [ ] Originality/prior work disclosed.

## Video

- [ ] 2–3 minutes.
- [ ] Public link, no login.
- [ ] Show actual diagnosis.
- [ ] Show benchmark.
- [ ] State only measured numerical claims.
