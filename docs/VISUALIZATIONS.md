# Q-Scope Visualizations

Q-Scope includes explanatory Manim animations and figures generated by the actual diagnostic pipeline.

## Manim animations

The animation source is:

`visuals/qscope_animations.py`

The rendered animations are stored in `assets/animations/`:

- `HamiltonianDrift.mp4` — shows a calibrated ZZ coupling drifting from its nominal value.
- `BayesianPosterior.mp4` — illustrates how finite-shot evidence changes the posterior over fault locations.
- `ExpectedInformationGain.mp4` — illustrates how Q-Scope compares candidate experiments and chooses the one expected to reduce uncertainty.
- `LocalizeCalibrate.mp4` — shows the switch from locating the faulty coupling to estimating its drift magnitude.

The posterior values shown in the animations are schematic examples used to explain the algorithm. They are not benchmark results.

## Generated results

The following files are generated by the actual Q-Scope run:

- `assets/results/qscope_dashboard.png`
- `assets/results/qscope_protocol.png`
- `assets/results/qscope_measurement.png`
- `assets/results/qscope_offgrid_benchmark.png`
- `assets/results/qscope_results.json`

To regenerate them, run:

```bash
python main.py
```

The animations explain how Q-Scope works; the generated figures show the outputs of the actual implementation.
